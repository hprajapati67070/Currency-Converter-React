# Currency Converter

A simple currency converter application built with React, Vite, and Tailwind CSS. It fetches real-time exchange rates from the Currency API.

## Features

- Real-time exchange rate updates
- Input field validation and clearability
- Interactive currency swapping (From <-> To)
- Clean responsive user interface

## Setup & Running

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```
